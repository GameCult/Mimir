Setting up the PlayStation 3 Eye Camera - Timocop/PSMoveServiceEx GitHub Wiki

[!WARNING] Before connecting or acquiring PlayStation 3 Eye cameras, first take a look at Compatible Devices and Hardware Requirements!

📷 PlayStation 3 Eye

🔌 Connection

Simply connect the PlayStation 3 Eye with any USB port on your Computer.

Do not exceed 5 meters of total cable length (including the 1 meter USB cable of the PlayStation 3 Eye camera), if you are using passive USB extensions cables. If you need to lay out cables over longer distances, its required to get active repeater USB cables or place USB Hub between them to repeat the data signals to avoid signal loss. Externally powered active USB repeater cables are not required as PlayStation 3 Eye cameras can still run at a very low USB voltage (~3.3v).

💿 Installation

To use the PlayStation 3 Eye camera, you will need LibUSB drivers in order for PSMoveServiceEx to receive image streams and change settings from the camera. You can use PSMoveServiceEx - Virtual Device Manager to install all necessary camera drivers.

Navigate to VDM - Service Management and click Install PlayStation Eye Drivers to install the drivers for the PlayStation 3 Eye camera.

[!NOTE] Those drivers are not compatible with DirectShow and PlayStation 3 Eye cameras will not show as Webcams in Microsoft Windows. Decreasing the risk of other applications accessing them.

⚙️ Configuration

Use PSMoveServiceEx Config Tool to configure the PlayStation 3 Eye camera. You can find all camera settings when calibrating controller or head-mounted display colors in Config Tool > Tracker Settings > Color Calibration

🧰 Troubleshooting

📌 PSMoveServiceEx Config Tool stream shows 'Tracker timed out.' or has a unstable framerate.

This means PSMoveServiceEx did not receive any image from the camera in a while or the image could not be received in time from the camera. This can be caused by the following reasons:

  • USB cable too long (signal loss).
  • Too many heavy-duty devices connected (such as cameras) to one USB Host Controller causing insufficient bandwidth.
  • Device disconnected.
  • Improper configuration (such as too high framerate).
  • Bad or broken cable.

[!NOTE] Please check Compatible Devices and Hardware Requirements to properly connect your PlayStation 3 Eye camera.

📌 PlayStation Eye 3 Cameras do not show in PSMoveServiceEx Config Tool.

Check if all camera drivers are installed properly as seen in 💿 Installation section of this page or restart PSMoveServiceEx. If they are installed properly and they still wont show up, check troubleshooting section 📌 PlayStation Eye 3 Cameras do not show in PSMoveServiceEx Config Tool..
